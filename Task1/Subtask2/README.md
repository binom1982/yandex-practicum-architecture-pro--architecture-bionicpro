# Изменения

## Изменения в realm-export.json

| **Параметр**                | **Значение** | **Что означает и зачем нужно**                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ----------------------------------------- | -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `standardFlowEnabled`                   | `true`                   | Включает Authorization Code Flow .<br />Это базовый OAuth 2.0-поток для браузерных и мобильных приложений. <br />PKCE — это расширение именно этого потока, поэтому без него PKCE не активируется.                                                                                                                                                                         |
| `publicClient`                          | `true`                   | Помечает клиент как публичный .<br /> Фронтенд (React/SPA) исполняется в браузере, где код открыт. <br />Хранить `client_secret`в таком окружении небезопасно. <br />Keycloak перестаёт требовать секрет и вместо него полагается на PKCE.                                                                                                |
| `directAccessGrantsEnabled`             | `false`                  | Отключает Resource Owner Password Credentials (ROPC) поток.<br />При нём приложение напрямую собирает логин/пароль и отправляет их в Keycloak. <br />Это обходит MFA, SSO, страницу входа и запрещено в OAuth 2.1. <br />Отключение гарантирует, что авторизация проходит только через защищённый редирект. |
| `attributes.pkce.code.challenge.method` | `"S256"`                 | Включает PKCE и задаёт алгоритм хеширования `code_verifier`→`code_challenge`.`S256`= SHA-256. <br />Это криптографически стойкий метод, который заменяет `client_secret`для публичных клиентов <br />и делает перехваченный `authorization_code` бесполезным без исходного `verifier`.                                            |
